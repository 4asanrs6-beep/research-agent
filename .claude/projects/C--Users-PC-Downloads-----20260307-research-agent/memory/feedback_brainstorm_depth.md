brainstormスキルで問いを生成すると、会話中に直接書いたものより浅くなる。

**Why:** スキルのプロンプトは会話の全文脈（何回も差し戻された経験、なぜ浅いのかの議論）を持てないため、指示だけでは深さが出ない。

**How to apply:**
- スキルのプロンプトには必ず**few-shot例**（実際の深い問い全文）を埋め込む
- 各問いに**二段構え以上の判定基準**を必須とする
- discussion.mdへの記録は**テーブル圧縮禁止、問いの全文を記載**
- 「知見の複数を同時に使わないと立てられない問い」だけを残す基準を明記
- ❌浅い問いの具体例も埋め込むことで下限を示す
