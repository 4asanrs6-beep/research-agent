# vol-reversal-specificity: vol反転はショック固有か通常ドリフトか

- 📊 需給: **進めるべき** — ショック日には流動性供給者（マーケットメーカー/HFT）が一時的にリスクオフする。その分のスプレッド拡大→回復がvol反転の本質なら、非ショック日には発生しないはず

# turnover-momentum-disentangle: turnover継続下落はモメンタム混入か真の売り圧力か
