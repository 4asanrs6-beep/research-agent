# cq3新 Stage 1: 保有者の不安定さ仮説 — 回転率の独自効果確認

## 問い
信用残が効かず回転率だけが効くのは、超過下落の原因が「レバレッジ解消」ではなく「保有者の不安定さ（短期で逃げる投資家の密度）」にあるからか。

Stage 1の検証: ボラティリティを統制した後でも回転率が超過下落を有意に説明するか。

## 設計
- 前回cq3 v2と同一パネル構築ロジック（S&P500 2σ下落日→翌営業日の超過リターン）
- 信用残を回帰から完全除外
- Model A: excess_ret ~ beta + vol + scale_dummies + ret5d（turnoverなし）
- Model B: excess_ret ~ beta + vol + turnover + scale_dummies + ret5d
- SE: event_date 1-way cluster（前回と同一）
- 期間: 2019-01-01〜2026-03-29
- 銘柄: JP上位200銘柄

## 結果

| 指標 | Model A (turnoverなし) | Model B (turnoverあり) |
|---|---|---|
| R2 | 0.0140 | 0.0155 |
| 増分R2 | — | **0.0015 (0.15%)** |

| 変数 | 係数 | t値 | p値 |
|---|---|---|---|

| ret5d | +0.01299 | +0.328 | 0.743 |

|---|---|---|---|---|

### 判定結果

| 条件 | 結果 |
|---|---|
| (1) turnover係数が負 | PASS |
| (2) p<0.10（1-way cluster SE） | PASS (p=0.026) |
| (3) 有効イベント>=20 | PASS (45日) |
| (4) 両期間で符号負 | PASS (-0.00227, -0.00258) |
| (5) 各期間で係数>=全期間の25% | PASS (前半88%, 後半101%) |
| (6) 増分R2>=0.1% | PASS (0.15%) |

**結論: Stage 1通過。Stage 2に進む。**

## 解釈

1. **回転率はボラとは独立に超過下落を説明する（p=0.026）。** ボラと回転率の相関はほぼゼロであることがVIF=1.07から確認済み（前回cq3 v2）。今回の結果はそれと整合的
2. **効果は期間を通じて安定。** 前半・後半で符号が一致し、係数の大きさも安定（88%〜101%）。ただし前半は単独では有意水準に達しない（p=0.176）
3. **βは依然非有意（p=0.576）。** 前回知見と完全に一貫
4. **volはp=0.0004で前回（p=0.026）より強化。** 信用残を除外したことでサンプルが増えた効果

## 注意点

- vol_pが前回（0.026）と乖離（0.0006）。信用残を除外したことで観測が増え、推定精度が上がった可能性が高いが、パネル構成が微妙に異なることは留意
- 前半期間は単独では非有意（p=0.176）。サンプル分割による検出力低下が主因と考えられるが、前半の効果が弱い可能性も否定できない
- 1-way cluster SE。2-way cluster SEでの補助確認は未実施（Stage 2で実施予定）
